# Fundamentos y Pentesting

## Herramientas web

- **Exploit-DB** — Archivo público de exploits y PoC. <https://www.exploit-db.com/>
- **Google Hacking Database (GHDB)** — Colección de *dorks* para localizar información expuesta. <https://www.exploit-db.com/google-hacking-database>
- **CVE Details** — Buscador de vulnerabilidades (CVE) por producto y tipo. <https://www.cvedetails.com/>
- **MITRE CVE** — Listado oficial de identificadores CVE. <https://cve.mitre.org/>
- **OWASP** — Referencia en seguridad de aplicaciones (Top 10, guías). <https://owasp.org/>
- **Kitploit** — Pagina con diferentes herramientas de pentesting. <https://kitploit.com/es>
## Herramientas de terminal / escritorio

- **Kali Linux** — Distribución para pentesting con herramientas preinstaladas. <https://www.kali.org/>
- **Parrot OS** — Distribución alternativa orientada a seguridad. <https://www.parrotsec.org/>
- **nmap** — Escáner de red, puertos y servicios.
  ```bash
  nmap -sV -p- objetivo.com      # servicios y versiones en todos los puertos
  ```
  <https://nmap.org/>
